# 학습 현황

## 현재 위치

문제 8의 정답 설명까지 확인했습니다. 다음 새 문제는 문제 9이며 아직 작성하지 않았습니다. 사용자가 계속 요청해 온 순차 학습 흐름을 이어갑니다.

## 다음 진행

사용자가 “다음”이라고 요청하면 Kotlin 개발자 관점의 새 가상 응용 문제 9를 한 개 제시합니다. 복습은 사용자가 복습을 요청할 때 해당 문제로 진행합니다. 문제 9는 새로 구성할 문제이며 실제 CJENM 기출이라고 부르지 않습니다.

## 확인된 기록과 범위

- 문제 1~3: 사용자가 제공한 이전 학습 노트에 기본 시나리오 채점 통과 기록이 있습니다. 이번 정리 과정에서는 원본 테스트를 재실행하지 않았습니다.
- 문제 4: 인접한 React Native 설치 타입을 사용한 과거 타입 검사 통과 기록이 있으며 실제 RN 앱 실행은 하지 않았습니다.
- 문제 5~8: 정답 설명을 확인하고 논리 검토한 기록만 있습니다. 실행 및 타입 검사는 하지 않았습니다.
- 사용자가 직접 각 문제 구현을 완료했다는 기록은 없습니다. 모든 문제 구현이나 테스트가 완료된 것은 아닙니다.
- 문제 1~3의 원래 출발 프로젝트와 테스트 서버 파일은 현재 자료에 없습니다. 문제 4~8은 원문 문제 파일이나 원래 자동 채점 환경을 확보하지 못한 재구성·응용 연습입니다. Node 24 이상이 필요하다는 이전 설명도 테스트 원본이 없어 재현할 수 없습니다.

## 연습 규칙

- Kotlin 개발자 기준으로 TypeScript와 React Native 대응을 설명하되 실행 모델이 동일하다고 단정하지 않습니다.
- 한 번에 문제 하나만 제시하고 사용자가 답하기 전에 정답을 먼저 공개하지 않습니다.
- 힌트 요청에는 규칙 하나만 제공합니다.
- 정답 요청에는 블록별 설명과 자주 하는 실수 표를 제공합니다.
- 문제 1~3은 사용자가 제공한 학습 노트 기반입니다. 문제 4~7은 원문 미확보 상태에서 재구성했고, 문제 8은 가상 응용 문제입니다. 실제 CJENM 기출로 표현하지 않습니다.
- 코드 조각 실행에 필요한 타입/API가 빠져 있으면 먼저 명시합니다. React Native TSX는 Node.js에서 직접 실행할 수 없습니다.
